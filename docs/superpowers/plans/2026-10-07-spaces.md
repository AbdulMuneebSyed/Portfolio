# Multiple Desktops (Spaces) Plan

**Goal:** macOS Spaces in MuneebOS: several desktops, shown as a strip at
the top of Mission Control, opened with a trackpad swipe up.

**Constraint:** browsers never receive three- or four-finger gestures (macOS
consumes them). Two-finger swipes arrive as `wheel` events, so MuneebOS uses
two fingers on the empty desktop. Swipes over a window keep scrolling it.

**Work style:** one checkpoint at a time; the user tries each before the next.

## Checkpoints

1. **Gesture** — two-finger swipe up on the empty desktop opens Mission
   Control; swipe down closes it. Detector in `lib/trackpad-swipe.ts`
   (one swipe per gesture, momentum ignored, mouse-wheel notches ignored).
   ✅ Done 2026-10-07.
2. **Desktops, folders, switching** (merged checkpoints 2–3, plus desktop
   files, which the first plan missed). ✅ Done 2026-10-07.
   - Mission Control strip: thumbnails, **+** (max 6), **×** (windows and
     files move to the neighbour), click to switch.
   - Each desktop has its own windows and files; windows stay mounted
     (hidden) so apps keep their state.
   - Right-click desktop › New Folder (rename inline); folder menu: Open,
     Rename, Move to Trash, Move to Desktop N, Move to New Desktop.
     Portfolio files can move between desktops but not to the Trash.
   - Trash: Put Back (to its original desktop), Empty Trash with confirm.
   - Window menu › Move to Desktop N / New Desktop.
   - Two-finger swipe left/right on the desktop, Ctrl+←/→, Ctrl+1…6;
     slide-in animation and a "Desktop N" overlay. Activating a window on
     another desktop (Dock, Window menu, Spotlight) switches there.
   - Clean Up now tidies only the current desktop (it used to reset all
     files, which would have deleted folders).
3. *(merged into 2)*
4. **Dragging** ✅ Done 2026-10-07.
   - Mission Control: drag a window onto a desktop thumbnail (or onto **+**
     for a new desktop); a card follows the pointer and the target lights up.
   - Desktop files: hold a dragged file (or selection) at the left/right
     screen edge ~0.65 s; the edge glows, the neighbouring desktop slides in
     and the drag continues there.
   - Switching animates with the Web Animations API on `translate`, so
     nothing remounts mid-drag.
5. **Polish** ✅ Done 2026-10-07.
   - Off below 700px: phones show every window and no strip or gestures.
   - System Settings › Desktop & Dock › Desktops (count, Add Desktop);
     Keyboard Shortcuts lists ⌃←/→, ⌃1…6, ⌘⌫ and a Trackpad group.
   - Help › Keyboard Shortcuts & Gestures…; a one-time gesture tip 20 s
     after the first unlock on a Mac-sized screen.
   - README section. Thumbnails show each desktop's windows and files;
     the "Desktop N" overlay shows on every switch.
